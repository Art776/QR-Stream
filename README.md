# Animated QR Data Transfer

Проект для передачи произвольных текстовых данных через последовательность сменяющихся QR-кодов (офлайн-стриминг данных с экрана на камеру).

## Структура проекта
- `index.html` — Главное меню для выбора роли.
- `sender.html` — Отправитель: разбивает текст на пакеты и циклично крутит QR-коды на экране.
- `receiver.html` — Получатель: использует камеру устройства, собирает недостающие кадры и восстанавливает исходный текст.

## Как запустить?
1. Положите все файлы в одну папку.
2. Откройте `index.html` в браузере (или запустите локальный сервер, например, через `npx serve` / VS Code Live Server, чтобы камера работала без проблем с разрешениями).
3. Перейдите в **Отправитель**, чтобы запустить анимацию.
4. Откройте **Получатель** (можно на телефоне) и наведите камеру на QR-коды.
